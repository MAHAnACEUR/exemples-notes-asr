# Module 1 — Administration système
## Objectifs
- Identifier les composants d’un système informatique
- Comprendre le rôle d’un système d’exploitation
- Appliquer les bonnes pratiques d’administration
- Documenter une intervention technique
## Notions importantes
| Notion | Définition |
|---|---|
| Système d’exploitation | Logiciel qui permet d’utiliser et de gérer les ressources
| Serveur | Ordinateur ou logiciel qui fournit un service à d’autres machines |
| Client | Poste ou logiciel qui utilise un service fourni par un serveur |
| Compte administrateur | Compte disposant de droits élevés sur un système |
| Mise à jour | Installation de correctifs ou de nouvelles versions d’un logiciel |
## Bonnes pratiques
- Utiliser un compte utilisateur standard pour les tâches quotidiennes
- Employer un compte administrateur uniquement lorsque nécessaire
- Documenter chaque modification importante
- Effectuer des sauvegardes avant une opération sensible
- Installer régulièrement les mises à jour de sécurité
## Exemple de procédure
### Vérifier les informations système sous Windows
1. Ouvrir le menu Démarrer
2. Rechercher `Informations système`
3. Vérifier le nom du poste, la version de Windows, la mémoire installée et le proces
4. Noter les informations utiles dans la documentation
## Exemple réalisé en TP
Nous avons identifié les caractéristiques d’un poste de travail :
- Nom du poste : `PC-TP-01`
- Système d’exploitation : Windows 11 Pro
- Mémoire vive : 8 Go
- Processeur : Intel Core i5
